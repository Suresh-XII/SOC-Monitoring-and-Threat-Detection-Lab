# Investigation Reports

Create one report per successfully tested detection. Use the template in `08-Documentation/incident-report-template.md`. Label simulated activity clearly, preserve timestamps/time zone, and distinguish observed facts from analyst assessment.

The Windows authentication example in `Authentication/` reflects the earlier Event ID 4625 screenshot. `Brute-Force/ssh-brute-force-investigation.docx` and its Markdown companion document the SSH evidence, including the 671-event dashboard count, the 271-event detailed search, and the `main` versus `blue` index discrepancy. Both reports flag unresolved points for validation and escalation.
